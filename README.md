### GitHub Profile Finder (API + React)

    Search any GitHub username
    First the similar names are being fetched from https://api.github.com/search/users?q=${name} (the name entered in the search box)
    Get a profile picture and name
    The Direct link to their profile on github https://www.github.com/$user.login ($user.login = the user name which has been selected)
